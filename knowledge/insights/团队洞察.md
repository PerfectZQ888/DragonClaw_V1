# 团队洞察与发现

> 记录日常工作中发现的技巧、经验总结

## 2026-03-23

### OpenClaw Agent 协作发现
- Agent 之间通过飞书可以无缝传递任务
- Dashboard 可以实时监控任务状态
- 记忆文件同步机制确保任务状态可见

### 飞书集成要点
- 飞书任务 API 需要开通相应权限才能使用
- tavily-search 适合通用搜索，weather skill 适合天气查询
- 在 main agent 配置 tavily-search 可提升搜索能力

### 监控平台优化
- 任务状态需要同步写入记忆文件才能被监控获取
- Dashboard 数据每 5 秒刷新一次
- /data 目录适合存放团队共享文件
